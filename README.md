# ⏱ ArbeitzeitPro

Eine schlanke, datenschutzfreundliche Arbeitszeiterfassungs-App — komplett als einzelne HTML-Datei, kein Server, keine Cloud-Pflicht.

## Features

- **Wochenübersicht** mit Navigation und Kalenderauswahl (📅)
- **Burger-Menü** (☰) — CSV, Backup, Import, Einstellungen, Design-Toggle
- **Arbeitskategorien** — Job, Hobby, Ehrenamt, Sonstiges (anpassbar)
- **Dashboard** — Charts & Statistiken (Chart.js)
- **Dark/Light Mode** — automatisch oder manuell
- **Lokale Datenspeicherung** — alles im Browser (`localStorage`)
- **Cloud-Vorbereitung** — Storage-Abstraktion für künftige Synchronisation
- **Android-App** via Capacitor 8.5.3

## Schnellstart

Einfach `arbeitszeiterfassung.html` im Browser öffnen — keine Installation nötig.

## Android

Das Komplettpaket enthält ein fertiges Capacitor-Projekt für Android Studio.

## Technologie

- **HTML/CSS/JS** — Single-File-App
- **Chart.js 4.4.1** — Dashboard-Charts
- **Capacitor 8.5.3** — Android-Wrapper
- **Inter** — Google Fonts

## Datenschutz

Alle Daten bleiben lokal im Browser. Kein Tracking, kein Server, keine Drittanbieter (außer Google Fonts CDN für die Schrift).
